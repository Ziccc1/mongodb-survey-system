# 统计占比与图表验证

日期：2026-10-17。

## 实现范围

- 标题包含手机号、电话、联系电话、phone/mobile 等关键词的数字题，统计页默认隐藏平均值。创建者可用显示平均值开关临时切换；普通数字题默认显示。规则仅用于展示，不修改题型或自动增加手机号位数、号段校验。
- 普通均值展示至多两位小数，API原始十进制字符串和数据库回答不改。显示开关不持久化，刷新或切换版本重新采用默认。
- 选项占比=count/answeredCount×100，最多一位小数。被跳过、可选留空的答卷不进入该题分母。单选支持饼图和柱状图，多选使用柱状图，明确合计可超过100%。
- 表格保留全部选项、次数和占比，图表不替代表格。零答卷时不画虚假的饼图。相同文字的不同选项使用独立ID作为饼图数据名。
- ECharts 6.1.0 依赖精确锁定；按需注册饼图/柱状图及SVG渲染器，图表组件异步加载、容器ResizeObserver自适应、卸载销毁。无API字段、数据库结构或业务数据变更，无需迁移或重新发布。
