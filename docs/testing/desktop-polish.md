## 视觉方案与实现

本轮目标是完整的桌面问卷产品，而非继续删减内容。白色主要内容面、浅蓝工作区与选中态、鹅黄提示和辅助图形，统一线性SVG图标、细边框、轻微阴影、标题/正文/辅助说明层级。桌面主断点1000px；保留原紧凑屏幕可用性，本轮不增加独立移动设计。

- 首页：浅蓝欢迎区与真实产品流程提示；创建入口为主要操作，带问卷结构图形，管理入口为白色辅助区；下方读取现有 `GET /surveys?limit=4`，展示最近创建问卷。接口按创建时间排序，因此明确标为“最近创建”，不冒称最近编辑，不虚构总数。
- 登录/注册：同一左右整体构图，左侧是明确标注的“问卷结构示意”，不是业务问卷或虚构统计；右侧为表单、说明、校验与账号切换。线性图标和少量浅黄色标签连接两部分。
- 列表：复用SurveyRows，名称/当前版本、状态、创建时间、真实累计答卷和管理操作固定列布局。图标与悬停提示明确整行可进入，原分页保留。
- 编辑器：左侧有题目目录、当前题目标识和直达入口；中央基本信息可展开、题目按原顺序编辑；右侧独立保存与发布管理。新增后仍聚焦题干，底部四题型添加入口独立可用。目录、基本信息折叠及校验/跳转折叠帮助跳过无关内容；均不卸载本地编辑值。所有高级配置默认可见，用户可折叠。已有题目的问卷默认折起基本信息，空草稿默认展开；修订冲突处理不变。
- 正式问卷：一整份白色问卷，浅蓝标题区、轻量图标与说明、原题号、选中态和轻分隔；每页最多10道有效题，不是每题独立卡片。
- 统计：版本栏、三种答卷份数、每题报告分区；桌面图表与明细表并排。没有新增图表，ECharts默认色板、占比口径和既有均值范围不变。
