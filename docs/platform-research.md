## D04 多选跳转的课程要求

作业原文的题目跳转功能同时列出单选结果、多选结果、数字填空内容跳转。因此单选更直观也不能作为移除多选跳转的依据。建议将整组选择作为输入，按规则顺序首条命中生效；用户尚未确认该方案。

## D06 发布后修改

- [Google 表单编辑帮助](https://support.google.com/docs/answer/2839737?hl=zh-Hans)明确提供编辑问题、标题、说明及删除内容的操作；该页未说明已有答卷时不同修改操作的数据保留细则，不能据此声称任何修改都安全。
- [Google 表单答卷管理帮助](https://support.google.com/docs/answer/139706?hl=en)明确已发布表单可停止收集答卷。这证明收集状态可单独控制，不足以证明暂停是编辑的强制条件。
- [问卷星入门帮助](https://www.wjx.cn/help/help.aspx)说明问卷编辑、发布和回收流程；[官方接口说明](https://www.wjx.cn/help/help.aspx?catid=136)提供发布与暂停状态。此次未找到直接、完整解释“发布后已有答卷时，哪些题目修改会怎样影响旧数据”的官方条款。
- 未将搜索到的第三方文章或帮助社区志愿者回复当作平台官方规则；也不推断平台内部是否采用版本快照。

本项目新建议，待确认：草稿自由编辑；发布后先暂停收集，无答卷可修改结构并重新发布；已有答卷则锁定题目、选项、校验和跳转，需修改时复制新问卷。保留截止与关闭等管理操作。此方案是项目取舍，不是对问卷星或 Google 内部实现的复刻。

## D11 非必答与校验

- [问卷星官方接口说明](https://www.wjx.cn/help/help.aspx?helpid=503)把是否必填 is_requir 与多选 min_options/max_options、文本 min_words/max_words 分开描述，支持在 Schema 中分别建模。
- [Google 设置表单规则帮助](https://support.google.com/docs/answer/3378864?hl=zh-Hans)列出文本长度上下限和多选至少、最多、恰好选中数量；[编辑帮助](https://support.google.com/docs/answer/2839737?hl=zh-Hans)另列必填开关。
- 上述页面未直接说明“非必答 + 正数最小限制 + 空回答”组合的全部行为。因此“空值跳过校验，非空执行约束”是本项目建议，不能写成已实测证实的问卷星行为。

本项目建议，待确认：非必答题留空允许通过；填写后必须满足长度、数量、类型等约束。对空字符串、纯空格、空数组的判空规则在实现时明确定义，数值 0 不是空值。
