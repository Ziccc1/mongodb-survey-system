## 核心实现

Vue 3/TypeScript/Vite + Fastify 5 + MongoDB原生驱动/Decimal128。共享模块统一题型、文本计数、十进制、答案校验和路径计算。所有业务数据在users、surveys、survey_versions、responses四集合，未引入关系数据库、ODM或现成问卷框架。

surveys保留可编辑定义与稳定身份，survey_versions保存每次正式发布的完整定义和策略事实，responses引用提交时版本。发布事务同时插快照、切指针和重置当前计数；提交事务同时插答卷并更新两项计数。应用仓储没有快照update/delete方法，读取校验定义hash；普通保存不产生发布快照。

后端生成身份、record ID、publicId、时间、版本和计数，不信任客户端这些字段。所有权检查贯穿管理接口；DTO白名单排除账号关联、请求key/hash及内部字段。幂等唯一索引和部分唯一防重复索引保持问卷级作用域，不因重新发布解锁。

API只维护一份契约。前端单独负责交互与提示，最终校验/路径及并发资格由后端保证。MongoDB严格验证器/索引保证形状和唯一性；跨集合原子性使用真实副本集事务，配置/引用/路径语义不冒充数据库验证器自动提供。

## 尚未落实与限制

- 当前本地MongoDB无认证，仅回环绑定。角色模板已提供，数据库级快照仅find/insert权限尚未启用/验收；应用仓储/API保护不能替代数据库权限，也不能阻止管理员直接改库。
- 未执行未知旧库/legacy定义或hash迁移，未删改旧数据；旧迁移专项仍为后续计划。若接入未知库须先备份/审计并按增量迁移门禁处理。
- 自动保存、断点恢复、复制问卷、去重人数、跨版本合并不实现。提交不确定时必须留在原页重试；跨刷新恢复不在本阶段范围。
- 退出只清cookie，未实现服务端JWT撤销/刷新。单节点不提供高可用，未作公网生产部署、生产负载/多节点故障或完整无障碍认证。
- 本轮未新增或修改任何AI使用日志，已有记录保持原文。项目报告和测试记录不冒充AI交互导出。
