# 题目编辑增量与实际验证（AI-015）

日期：2026-10-16。沿用0.1.0工程，不修改已确认业务规则；接口仍为docs/api.md的Q04/Q05。发布、正式填写、答卷和统计不在本轮范围，无自动保存。

## 实际实现与使用

现有问卷详情路由改为EditorPage；从“我的问卷”进入，分别手动保存基本信息和题目。标题/说明继续共用Unicode码点计数，说明2000限额与就地超限提示保留。题干最多500、选项文字最多200。新题目、选项、规则使用crypto.randomUUID，删除/排序/保存/刷新均不重新分配ID。

四题型可添加/删除/上下移动，编辑题干、必答和选项。多选配置最少/最多（相同即恰好）；文本配置长度；数字以字符串配置范围及整数限制。单选、多选、数字规则提供条件、后续目标和上下优先级；数组顺序就是优先级。文本无跳转编辑。

Q04只更新传入字段：标题trim、说明原文；Q05整体替换questions。硬约束阻止保存，形状合法的缺失条件选项、缺失目标、非向后目标及发布前不可满足必答/整数约束以validationIssues保留草稿。未选目标使用稳定待完善引用，不新增假题目。问题提示区展示用户可读信息，不要求用户理解字段名。

后端最终保证归属、状态、冻结策略及revision；更新用_id+ownerId+revision过滤原子写入。无变化保留revision、definitionVersion和updatedAt；标题/说明/题目变化时编辑修订+1，单改截止或策略仅revision+1。数字比较用decimal.js 10.6.0，数字字段存为BSON Decimal128、DTO转回字符串；数学同值和对象键顺序不会误增版本。

冲突保留本地元数据和题目，读取服务器内容供比较；可确认放弃本地，也可明确采用最新修订号、保留本地后手动保存。后者保存题目仍是整体替换，不自动合并。未知保存结果同样要求先核对，离开未保存页面会提示。
