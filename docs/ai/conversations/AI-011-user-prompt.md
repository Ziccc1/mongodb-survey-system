请将现有 API 设计独立整理为 docs/api.md，作为前后端共同遵循的
接口契约。本轮只做设计文档，不实现业务代码。

阅读最新 system-design.md、database-design.md、decisions.md、
versioning-change-plan.md 和 test-plan.md，沿用已有设计，
不要另起一套接口。

请完成：

   ID、时间、数字字符串和分页约定。

   不擅自扩展业务范围。
7. system-design.md 保留接口概览，详细契约引用 api.md，
   避免两份文档重复维护。
8. 更新 README 入口和真实 AI 使用日志。

普通接口细节可自主确定并说明理由；涉及改变已确认业务行为时，
单独列出，不静默覆盖。不要将文档完成描述成接口已经实现。
