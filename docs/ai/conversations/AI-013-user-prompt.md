# AI-013 实际用户提示词

请根据 project1 中最新的总体设计、数据库设计和 API 契约，
开发第一版可以实际操作的系统，不要只搭空工程。

本轮完成：
1. 建立前端、后端及共享模块工程，锁定兼容依赖。
2. 配置项目专用 MongoDB 单节点副本集，落实新版四集合初始化，
   保留已有文件和数据，不直接迁移未知旧库。
3. 实现注册、登录、读取当前用户和退出。

5. 提供对应页面：注册、登录、问卷列表、创建表单及简单详情。
   创建后能看到刚创建的草稿，刷新页面后数据仍然存在。
6. 未登录不能管理问卷，用户不能查看或修改其他人的问卷。

沿用 docs/api.md 的接口与字段，不另外设计一套协议。

页面不显示尚不可用的功能按钮。
