# AI-015 用户任务原文

请在现有第一版系统上实现题目编辑，沿用最新 API 契约和数据库设计。
先检查当前代码，保留刚完成的字符计数修正。

本轮完成：
1. 实现契约中的 Q04 元数据修改和 Q05 整体保存题目接口。
2. 提供单选、多选、文本、数字四种题型的编辑界面：
   - 添加、删除、上移和下移题目；
   - 编辑题干、必答设置；
   - 编辑选择题选项；
   - 配置数量、文本长度、数字范围及整数限制。
3. 提供单选、多选、数字题的跳转规则编辑：
   可选择条件、后续目标题目，并调整规则优先级。
4. 保存到 MongoDB，刷新后恢复内容；题目、选项和规则使用稳定 ID。
5. 按契约校验配置，展示 validationIssues；
   草稿允许保留的未完成跳转引用不要提前当作发布错误拒绝。
6. 落实创建者权限和 revision 并发检查。
   保存无实际变化时不递增版本，冲突时保留本地编辑并提示。

本轮不实现发布、正式填写、答卷提交或统计，也不扩展自动保存。
普通实现细节自主决定，只读取相关文档章节。

实际验证四种题型及规则的保存恢复、非法约束提示、
跨用户修改拒绝和过期 revision 冲突，再运行类型检查与构建。
只检查本轮相关范围，不重复运行无关检查。

完成后简要汇报修改内容、使用方法、实际验证结果和未完成项，
同步受影响的文档，并追加真实 AI 使用日志。

仅保存本轮用户提示词，不冒充完整往返对话导出。
