## 公共前置与样本

未来在独立测试副本集运行；创建者 A、其他创建者 B、填写者 X/Y；账号和密码通过真实注册流程或真实哈希 fixture 生成。版本化样本使用 allowRepeat=true 验证跨版填写；另建 allowRepeat=false 问卷验证原全问卷限制。

版本 v1：单选题 q1 的 b 标签为“香蕉”，数字 q2 的整数范围 0—120；先产生 2 份成功答卷。暂停后将 b 改为“葡萄”、修改 q2 校验及跳转并可新增/删除题目，发布 v2，产生 1 份成功答卷。每次提交使用不同 requestId，记录一份 v1 成功请求的原始内容与 key 供重放。示例编号只作便于复现的输入，不是教师指定业务内容。
